# Linux 工具教程模板

## 文章结构

每篇文章必须包含以下部分：

### Front Matter

```yaml
---
title: {文章标题}
date: {YYYY-MM-DD HH:mm:ss}
updated: {YYYY-MM-DD HH:mm:ss}
tags:
  - {工具名}
  - Linux
categories:
  - Linux 工具
description: {50-100字摘要，说明这篇教程解决什么问题}
cover: https://picsum.photos/seed/{关键词}/1920/1080
source_file: {参考文件名}
---
```

## 验收标准

| 元素 | 要求 | 最低数量 |
|------|------|---------|
| 代码块 | 必须注明语言 | ≥2 个 |
| 配置示例 | Bash/YAML/JSON，可直接执行 | ≥1 个 |
| 表格 | 有表头，如验证清单、参数说明 | ≥1 个 |
| 踩坑经验 | 具体的报错和解决步骤 | ≥1 条 |
| 字数 | 不含 Front Matter | ≥1000 字 |

## 禁止出现的空洞内容

- "实践出真知"等套话
- 没有命令的纯文字描述步骤
- 重复标题但没有实质内容

## 写作风格

- **受众**：有一定 Linux 命令行基础
- **语气**：轻松、直接，像朋友讲解
- **专业术语**：出现时必须用括号或一句话解释
- **长度**：1500-2500 字
