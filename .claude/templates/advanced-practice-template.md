# Claude Code 实战进阶文章模板

## 文章结构

每篇文章必须包含以下部分：

### Front Matter

```yaml
---
title: {文章标题}
date: {YYYY-MM-DD HH:mm:ss}
tags:
  - Claude Code
  - {实战案例|扩展定制}
categories:
  - AI 工具系列
series: claude-code-advanced
series_index: {序号}
description: {50-100字摘要}
cover: https://picsum.photos/seed/{关键词}/1920/1080
---
```

### 正文结构

```markdown
# {文章标题}

{1-2段引言：这篇文章讲什么、为什么要看、看完能得到什么}

<!-- more -->

---

{具体场景描述，有细节有代码}
```

## 验收标准

| 元素 | 要求 | 最低数量 |
|------|------|---------|
| 代码块 | 必须注明语言，可复制执行 | ≥2 个 |
| 命令/配置示例 | bash/yaml/json/go，真实可用 | ≥1 个 |
| 表格 | 有实际内容的对比或说明表 | ≥1 个 |
| 具体场景 | 有细节描述的经验分享 | 每篇 ≥2 个 |
| 字数 | 不含 Front Matter | 1000-2500 字 |

## 禁止出现的空洞内容

- "实践出真知，不如自己动手试一次"
- "让我们一起 xxx 吧"
- "以上就是 xxx 的全部内容"
- "相信你 xxx 掌握了"
- "希望这篇文章对你有帮助"
- 没有代码的纯文字堆砌
- 没有具体场景的泛泛建议

## 写作风格

- **受众**：有一定技术基础、已经在用 Claude Code 的开发者
- **语气**：直接、具体，像有经验的同事分享踩坑经验
- **专业术语**：不需要解释 Claude Code 基础概念（读者已有基础）
- **长度**：1000-2500 字
