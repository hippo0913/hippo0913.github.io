# 新建系列大纲页

## 用法
```
/blog-new-series
```
然后告诉我系列名称和计划包含的文章。

或者直接：
```
/blog-new-series 系列名称 | 文章1标题, 文章2标题, 文章3标题
```

## 执行流程

### 第一步：确认系列信息
向用户确认：
- 系列名称
- 系列简介（一句话）
- 计划文章列表（标题 + 一句话简介）

**等待用户确认后继续。**

### 第二步：创建大纲文章
```bash
hexo new "系列名称-系列大纲"
```

### 第三步：写入大纲内容

Front Matter：
```yaml
---
title: 系列名称 · 系列大纲
date: YYYY-MM-DD HH:mm:ss
tags:
  - 系列名称
  - 系列大纲
categories:
  - 系列名称
description: 本系列文章的导航索引，持续更新中
cover: https://picsum.photos/seed/series/1920/1080
---
```

正文格式：
```markdown
> 本页是「系列名称」系列的导航大纲，书签收藏本页，随时跳转到你需要的文章。

## 系列简介

一段话介绍这个系列要解决什么问题，适合什么人看。

## 文章目录

| # | 文章 | 简介 | 状态 |
|---|------|------|------|
| 01 | [文章标题](#) | 一句话简介 | ✅ 已发布 |
| 02 | 文章标题 | 一句话简介 | 🚧 写作中 |

## 更新日志

- YYYY-MM-DD：系列创建
```

### 第四步：本地验证并提示用户预览

### 第五步：等待用户确认后发布
```bash
git add .
git commit -m "post: 新建《系列名称》系列大纲"
git push
```

## 注意事项
- 大纲页文章链接在对应文章发布后要回来更新
- 每次发布系列新文章，都要同步更新大纲页的状态和链接
