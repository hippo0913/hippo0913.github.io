# 精读官方文档：在 Chrome 中使用 Claude Code（测试版）

> 💬 hippo：这是 Claude Code 官方文档精读系列的第 18 篇，讲的是如何把 Claude Code 连接到 Chrome 浏览器，让 AI 直接在网页上干活。

---

## 开篇：为什么要在浏览器里用 Claude Code？

想想这个场景：你在开发一个网页应用，需要测试表单填写、检查控制台日志、甚至要从网页抓取数据。传统做法是什么？手动点点点，打开开发者工具，复制粘贴，反反复复。

Chrome 扩展版的 Claude Code 解决的就是这个问题——**把 Claude Code 的 AI 能力直接带进浏览器**。

根据官方文档，它能帮你做四件事：
- 测试网络应用
- 使用控制台日志进行调试
- 自动填充表单
- 从网页中提取数据

简单说，就是让 Claude 帮你操作网页，省去大量重复劳动。

## 核心概念：大白话讲 Chrome 扩展

### 什么是 Chrome 扩展？

Chrome 扩展（Extension）就是给浏览器装的小插件，能扩展浏览器的功能。比如你装过的广告拦截器、翻译插件都是扩展。

Claude Code 的 Chrome 扩展本质上是一个**桥梁**：
- 一头连着 Claude AI（通过命令行或 VS Code）
- 一头连着你的 Chrome 浏览器
- 中间通过一种叫 CDP（Chrome DevTools Protocol，Chrome 开发者工具协议）的标准来通信

### 工作原理（用通俗的话说）

1. **安装扩展**：在 Chrome 网上应用店安装 Claude Code 扩展
2. **建立连接**：扩展监听特定端口，等待 Claude Code 命令行来连接
3. **执行指令**：Claude AI 发送命令，扩展通过 CDP 协议操控浏览器
4. **返回结果**：浏览器执行结果（截图、日志、元素信息）传回给 AI

> 💬 hippo：想象一下，你的浏览器成了 Claude 的"手"和"眼睛"。它能看到网页长啥样（截图），能操作网页元素（点击、填表），还能读取浏览器内部信息（控制台、网络请求）。

## 实战指南：手把手教你用

### 场景一：自动填写表单并提交

假设你要测试一个登录表单，需要输入用户名密码并点击登录。

**第一步：准备环境**

```bash
# 确保你的 Claude Code 版本支持 Chrome 扩展
claude --version
```

**第二步：安装扩展**

1. 打开 Chrome 浏览器
2. 访问 Chrome 网上应用店
3. 搜索 "Claude Code" 或使用官方提供的安装链接
4. 点击"添加到 Chrome"按钮

**第三步：让 Claude 帮你填表**

```bash
# 在终端里打开 Claude Code
claude

# 输入提示词
"帮我打开 http://example.com/login，填写用户名 'testuser'，密码 'password123'，然后点击登录按钮，截图给我看看结果"
```

Claude 会自动：
1. 控制浏览器打开指定网址
2. 找到用户名和密码输入框
3. 填入对应值
4. 找到登录按钮并点击
5. 截取页面截图反馈给你

**第四步：验证结果**

你可以看到：
- 浏览器自动操作的过程（如果启用了可视化）
- 最终的页面截图
- 如果有错误，Claude 会分析控制台日志

> 💬 hippo：这个功能对测试表单特别有用，尤其是那些需要反复填写、测试不同数据的场景。我以前手动填个 50 条测试数据，现在让 Claude 几分钟搞定。

---

### 场景二：调试网页问题

你的网页有个 bug，报错信息不清楚，需要查看控制台日志和网络请求。

**让 Claude 帮你调试：**

```bash
claude

# 输入提示词
"打开 http://example.com/problem-page，检查控制台有什么错误信息，分析可能的原因，网络请求有没有失败"
```

Claude 会：
1. 打开页面
2. 读取控制台日志（Console logs）
3. 检查网络请求（Network requests）
4. 分析错误原因
5. 给出修复建议

**常见问题的处理：**

```bash
# 场景：某个 API 返回 404
"帮我检查 http://example.com/api/data 为什么返回 404，查看请求的 URL 和参数是否正确"

# 场景：页面样式错乱
"打开 http://example.com，截图看看样式是否正常，检查控制台有没有 CSS 加载错误"
```

---

### 场景三：批量提取网页数据

你要从多个网页抓取商品信息、文章内容或其他数据。

**让 Claude 帮你抓取：**

```bash
claude

# 输入提示词
"帮我访问 http://example.com/products，提取所有商品的标题、价格和图片链接，整理成表格输出"

# 或者抓取列表页
"打开 http://example.com/news，提取前 10 篇新闻的标题和链接，然后依次打开每篇新闻，提取正文内容"
```

Claude 会：
1. 访问页面
2. 解析 HTML 结构
3. 提取你需要的数据
4. 整理成格式化的结果（JSON、表格等）

> 💬 hippo：这个功能特别适合做竞品分析、数据采集。不过要注意遵守网站的 robots.txt 和使用条款，不要过度爬取。

## hippo 的踩坑实录

### 坑点一：扩展连接失败

**问题现象：**

```bash
claude
"帮我打开 http://example.com"

# 报错：无法连接到 Chrome 扩展
```

**原因分析：**

1. Chrome 浏览器没有打开
2. 扩展没有安装或被禁用
3. 端口被占用
4. 扩展版本和 Claude Code 版本不匹配

**解决方案：**

```bash
# 1. 确认 Chrome 已打开
# 启动 Chrome 浏览器

# 2. 检查扩展是否启用
# 在 Chrome 地址栏输入：chrome://extensions/
# 确保 Claude Code 扩展已启用（开关是打开状态）

# 3. 重启扩展
# 点击扩展的"重新加载"按钮

# 4. 检查版本匹配
claude --version
# 在扩展设置里查看扩展版本，确保一致
```

> 💬 hippo：最常见的是忘记开浏览器，或者扩展被禁用了。现在我有了一个检查清单：浏览器开着？扩展开着？版本匹配？三步走一遍基本能解决。

---

### 坑点二：网页元素定位不准

**问题现象：**

```bash
"帮我点击登录按钮"

# Claude 找不到按钮，或者点错了地方
```

**原因分析：**

1. 页面使用了动态加载（AJAX、React、Vue 等）
2. 元素没有明确的标识（没有 id、class 等属性）
3. 页面有多个相似的按钮
4. 需要滚动才能看到目标元素

**解决方案：**

```bash
# 1. 明确指定元素
"点击 id 为 'submit-btn' 的登录按钮"
"点击 class 为 'btn-primary' 的按钮"
"点击文本内容为'登录'的按钮"

# 2. 指定位置
"滚动到页面底部，点击'加载更多'按钮"
"找到第一个文章卡片的标题链接并点击"

# 3. 先截图确认
"截个图，帮我确认登录按钮在哪里"

# 4. 分步操作
"先滚动到登录表单，截图看看，然后填写表单"
```

> 💬 hippo：复杂页面我从来不给模糊指令。我会让 Claude 先截图，我确认一下位置，再让它精确操作。多一步截图，少一步踩坑。

---

### 坑点三：跨域和安全限制

**问题现象：**

```bash
"帮我打开 http://example.com"

# 提示：由于跨域策略，无法读取页面内容
```

**原因分析：**

1. 网站有 CORS（跨域资源共享）限制
2. 网站使用了内容安全策略（CSP）
3. 网站检测到了自动化工具并拦截

**解决方案：**

```bash
# 1. 先截图试试
"截个图看看页面长什么样"

# 2. 使用代理或 VPN（如果网站有地区限制）

# 3. 模拟正常用户行为
"像正常用户一样访问页面，等待页面加载完成再操作"

# 4. 检查是否需要登录
"这个页面需要登录吗？如果需要，先帮我登录"
```

> 💬 hippo：有些网站反爬虫做得比较好，遇到这种情况我就手动操作一下，截图给 Claude 看，让它帮我分析页面内容，而不是让 AI 直接操作。

## 常见问题解答

### Q：这个功能免费吗？

A：Chrome 扩展本身是免费的，但它需要配合 Claude Code 命令行使用，而 Claude Code 的高级功能可能需要 Anthropic 的 API 或订阅。具体看你的使用场景。

### Q：除了 Chrome，支持其他浏览器吗？

A：目前官方只提到 Chrome 浏览器。理论上支持 Chromium 内核的浏览器（如 Edge、Brave）也可能兼容，但未官方保证。

### Q：能看到 Claude 操作浏览器的过程吗？

A：取决于扩展的具体实现。有些扩展可以实时展示操作过程，有些则是静默执行。你可以通过截图命令来查看操作结果。

### Q：可以同时操作多个标签页吗？

A：可以。Claude 可以在指令中指定打开新标签页、切换标签页、关闭标签页等操作。

### Q：数据安全吗？扩展会记录我的浏览历史吗？

A：这取决于扩展的隐私政策。建议：
1. 只从官方渠道安装扩展
2. 查看扩展的权限请求（是否需要访问所有网站数据）
3. 在处理敏感信息时谨慎使用
4. 定期检查扩展的更新和权限

### Q：可以用在移动浏览器上吗？

A：移动端浏览器的扩展生态和桌面端不同，目前这个功能主要针对桌面端 Chrome。
